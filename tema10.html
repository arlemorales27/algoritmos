Paso 1. ¿Qué es el DOM?

El profe: El DOM es una representación en árbol de tu HTML. Con JS podemos leer y modificar ese árbol. Cambiemos un saludo y un texto para verlo.

<main id="app">
  <h2 id="titulo">Saludo inicial</h2>
  <p id="mensaje">Estoy esperando que JS me cambie.</p>
</main>

#app{ padding:16px; border:1px solid #e5e7eb; border-radius:12px; }
.resaltado{ color:#1D4ED8; font-weight:700; }

document.addEventListener('DOMContentLoaded', () => {
  const titulo = document.getElementById('titulo');
  const mensaje = document.getElementById('mensaje');

  titulo.textContent = '¡Hola, DOM!';
  titulo.classList.add('resaltado');
  mensaje.textContent = 'El DOM es el árbol de tu página. JS puede leerlo y modificarlo.';
});

Paso 2. Seleccionar elementos

El profe: Con querySelector y querySelectorAll (tipo CSS) encontramos elementos. Resaltemos los que son .especial y contemos cuántos hay.

<h3>Frutas</h3>
<ul id="frutas">
  <li class="item">Manzana</li>
  <li class="item">Banana</li>
  <li class="item">Uva</li>
  <li class="item especial">Mango</li>
</ul>
<button id="btn-resaltar">Resaltar especiales</button>
<div id="cuenta"></div>

.item{ padding:.25rem .5rem; border-radius:.4rem; }
.destacado{ background:#e0f2fe; outline:2px dashed #3B82F6; }

document.addEventListener('DOMContentLoaded', () => {
  const lista = document.querySelectorAll('#frutas .item');
  const especiales = document.querySelectorAll('#frutas .especial');
  const btn = document.getElementById('btn-resaltar');
  const cuenta = document.getElementById('cuenta');

  cuenta.textContent = 'Total de frutas: ' + lista.length;

  btn.addEventListener('click', () => {
    especiales.forEach(li => li.classList.toggle('destacado'));
  });
});

Paso 3. Cambiar texto y estilos

El profe: textContent modifica texto. Para estilos, mejor usa classList (agrega o quita clases CSS).

<p id="parrafo">Texto original.</p>
<button id="btn-cambiar">Cambiar texto y estilo</button>

.bonito{ color:#1D4ED8; font-weight:700; background:#eff6ff; padding:.25rem .35rem; border-radius:.35rem; }

document.addEventListener('DOMContentLoaded', () => {
  const p = document.getElementById('parrafo');
  const btn = document.getElementById('btn-cambiar');

  btn.addEventListener('click', () => {
    p.textContent = '¡Nuevo texto desde JS!';
    p.classList.toggle('bonito');
  });
});

Paso 4. Crear e insertar nodos

El profe: createElement crea un nodo; append/prepend/before/after lo insertan. Hagamos una lista de tareas.

<form id="form-tarea">
  <input id="input-tarea" placeholder="Nueva tarea..." required/>
  <button>Agregar</button>
</form>
<ul id="tareas"></ul>

#tareas li{ padding:.25rem .5rem; border:1px solid #e5e7eb; border-radius:.35rem; margin:.25rem 0; }

document.addEventListener('DOMContentLoaded', () => {
  const form = document.getElementById('form-tarea');
  const input = document.getElementById('input-tarea');
  const lista = document.getElementById('tareas');

  form.addEventListener('submit', (e) => {
    e.preventDefault();
    const texto = input.value.trim();
    if(!texto) return;
    const li = document.createElement('li');
    li.textContent = texto;
    lista.append(li);
    input.value = '';
    input.focus();
  });
});

Paso 5. Eventos básicos

El profe: addEventListener te permite reaccionar a clicks, inputs, etc. Construyamos un contador.

<button id="inc">+1</button>
<span id="contador">0</span>
<button id="reset">Reiniciar</button>

#contador{ font-weight:700; margin:0 .5rem; }

document.addEventListener('DOMContentLoaded', () => {
  const inc = document.getElementById('inc');
  const reset = document.getElementById('reset');
  const c = document.getElementById('contador');
  let n = 0;

  inc.addEventListener('click', () => { n++; c.textContent = n; });
  reset.addEventListener('click', () => { n = 0; c.textContent = n; });
});

Paso 6. Delegación de eventos

El profe: Escucha un solo click en el contenedor y decide con event.target. Así los elementos nuevos también funcionan.

<div class="controls">
  <input id="todo-text" placeholder="Nueva tarea..."/>
  <button id="todo-add">Agregar</button>
</div>
<ul id="todo-list">
  <li>Comprar pan</li>
  <li>Estudiar DOM</li>
</ul>

#todo-list li{ cursor:pointer; padding:.25rem .5rem; border-radius:.35rem; }
#todo-list li.hecho{ text-decoration:line-through; background:#f3f4f6; }

document.addEventListener('DOMContentLoaded', () => {
  const list = document.getElementById('todo-list');
  const txt = document.getElementById('todo-text');
  const add = document.getElementById('todo-add');

  list.addEventListener('click', (e) => {
    const li = e.target.closest('li');
    if(!li) return;
    li.classList.toggle('hecho');
  });

  add.addEventListener('click', () => {
    const v = txt.value.trim();
    if(!v) return;
    const li = document.createElement('li');
    li.textContent = v;
    list.append(li);
    txt.value = '';
    txt.focus();
  });
});

Paso 7. <template> + DocumentFragment

El profe: Para crear muchos elementos, clona un <template> en un DocumentFragment y luego inserta todo junto (menos repintados, más rápido).

<div class="controls">
  <input id="n" type="number" min="1" value="6"/>
  <button id="render">Construir tarjetas</button>
</div>

<div id="grid" class="grid"></div>

<template id="tpl-card">
  <article class="card">
    <h4>Card <span data-slot="idx"></span></h4>
    <p>Descripción breve…</p>
  </article>
</template>

.grid{ display:grid; grid-template-columns:repeat(auto-fill,minmax(140px,1fr)); gap:.5rem; }
.card{ border:1px solid #e5e7eb; border-radius:.5rem; padding:.5rem; background:#fff; }

document.addEventListener('DOMContentLoaded', () => {
  const grid = document.getElementById('grid');
  const tpl = document.getElementById('tpl-card');
  const render = document.getElementById('render');
  const n = document.getElementById('n');

  render.addEventListener('click', () => {
    grid.innerHTML = '';
    const frag = document.createDocumentFragment();
    const total = Math.max(1, Number(n.value||6));
    for(let i=1;i<=total;i++){
      const node = tpl.content.cloneNode(true);
      node.querySelector('[data-slot="idx"]').textContent = i;
      frag.appendChild(node);
    }
    grid.appendChild(frag);
  });
});

Bonus. IntersectionObserver (reveal al hacer scroll)

El profe: Con IntersectionObserver sabes cuándo algo entra al viewport. Ideal para efectos de “revelar” o lazy‑load.

<div class="scrollbox">
  <div class="caja">1</div>
  <div class="caja">2</div>
  <div class="caja">3</div>
  <div class="caja">4</div>
  <div class="caja">5</div>
  <div class="caja">6</div>
</div>

.scrollbox{ height:280px; overflow:auto; border:1px solid #e5e7eb; padding:.5rem; }
.caja{ height:120px; margin-bottom:.5rem; background:#f3f4f6; display:flex; align-items:center; justify-content:center; border-radius:.5rem; opacity:.3; transform:translateY(8px); transition:all .35s; }
.caja.visible{ opacity:1; background:#e0f2fe; transform:none; }

document.addEventListener('DOMContentLoaded', () => {
  const cajas = document.querySelectorAll('.caja');
  const io = new IntersectionObserver((entries) => {
    entries.forEach(en => en.target.classList.toggle('visible', en.isIntersecting));
  }, { threshold: .25, root: document.querySelector('.scrollbox') });
  cajas.forEach(c => io.observe(c));
});
