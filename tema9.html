¿Por qué aprender asincronismo?

El asincronismo permite que JavaScript no se bloquee mientras espera tareas lentas (I/O, red, temporizadores). Es la base de las apps modernas: chats en tiempo real, paneles con datos, sitios rápidos.

Event Loop Promesas Async/Await try/catch

1) ¿Qué es asincronismo?

En JavaScript, el asincronismo es la capacidad de iniciar una tarea y seguir ejecutando otras mientras la primera termina en segundo plano. JS usa un único hilo y delega el trabajo lento a APIs del navegador o del entorno para luego reanudar con callbacks en la cola de tareas.

// Demostración: JS no se bloquea esperando setTimeout
console.log("A");
setTimeout(() => console.log("B (tarde)"), 500);
console.log("C");
// Orden esperado: A, C, B

2) Ejemplos de asincronismo en la vida cotidiana

  1. Pedir comida: haces el pedido (disparas tarea), sigues conversando (otras tareas), te llaman cuando llega (callback).
  2. Lavadora: inicias el ciclo y limpias la casa. Al terminar, suena (evento) y continúas con el siguiente paso.
  3. Semáforos: cada calle avanza cuando es su turno (cola de eventos).

3) ¿Qué es una promesa?

Una Promesa representa el resultado futuro de una operación. Tiene tres estados: pendiente, resuelta y rechazada. Se consumen con .then(), .catch() y .finally().

// Crear una promesa básica
const tarea = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Listo"), 400);
});

tarea
 .then(v => "Éxito: " + v)
 .then(msg => console.log(msg))
 .catch(err => console.error(err))
 .finally(() => console.log("Siempre se ejecuta"));

// Encadenamiento y manejo de errores
const falla = (n) => new Promise((res, rej) => {
  setTimeout(() => n % 2 ? res(n) : rej(new Error("Número par: falla")), 300);
});

falla(2)
 .then(n => n * 2)
 .catch(e => "Recuperado: " + e.message)
 .then(msg => console.log(msg));

5) Async/Await en 2025: forma recomendada

async/await es azúcar sintáctico sobre Promesas que permite escribir código asíncrono con apariencia secuencial. En 2025, se recomienda:

  • Usar await para claridad y Promise.all/allSettled para paralelo.
  • Encapsular en funciones async y manejar errores con try/catch.
  • No bloquear la UI: preferir operaciones concurrentes cuando sea seguro.
// Secuencial con async/await
const getValor = (v, ms) => new Promise(res => setTimeout(()=>res(v), ms));

async function demoSecuencial(){
  const x = await getValor(1, 300);
  const y = await getValor(2, 300);
  return x + y; // tarda ~600ms
}

demoSecuencial().then(console.log);

// Paralelo correcto en 2025
async function demoParalelo(){
  const p1 = getValor(1, 300);
  const p2 = getValor(2, 300);
  const [x,y] = await Promise.all([p1,p2]); // ~300ms
  return x + y;
}

demoParalelo().then(console.log);

6) Caso práctico: elaboración de un helado

Haremos un helado modelando cada paso como una operación asíncrona. Mezcla (paralela), enfriar (secuencial) y servir.

// Pasos del helado con async/await
const paso = (nombre, ms, falla=false) => new Promise((res, rej) => {
  setTimeout(() => falla ? rej(new Error(`Falla en ${nombre}`)) : res(`✔ ${nombre}`), ms);
});

async function hacerHelado(){
  const [mezclarBase, mezclarSabor] = await Promise.all([
    paso("Mezclar base", 300),
    paso("Mezclar sabor", 300)
  ]);

  const enfriar = await paso("Enfriar mezcla", 400);
  const servir = await paso("Servir bolas", 200);

  return [mezclarBase, mezclarSabor, enfriar, servir];
}

hacerHelado()
 .then(steps => steps.forEach(s => console.log(s)))
 .catch(e => console.error("Error:", e.message));

7) ¿Qué es una excepción? Manejo en JavaScript

Una excepción es un evento de error que interrumpe el flujo normal. En JS moderno se maneja con try, catch y finally. En funciones async, los rechazos de promesas se capturan con try/catch.

// try/catch sincrónico
try {
  JSON.parse("{mal}");
} catch (e) {
  console.log("Capturado:", e.message);
} finally {
  console.log("Siempre se ejecuta");
}

// try/catch en async/await
const aVecesFalla = () => new Promise((res, rej) =>
  setTimeout(()=> Math.random()<0.5? res("ok") : rej(new Error("random fail")), 300)
);

async function robusto(){
  try{
    const r = await aVecesFalla();
    return "Resultado: " + r;
  }catch(e){
    return "Manejé el error: " + e.message;
  }finally{
    console.log("Limpieza");
  }
}

robusto().then(console.log);

8) Consumo de una API básica y mostrar el asincronismo

Usaremos fetch para obtener datos públicos. Observa el estado de cargando mientras la red responde.

// Fetch con manejo de errores y cancelación
async function cargarUsuario(signal){
  const res = await fetch("https://jsonplaceholder.typicode.com/users/1", { signal });
  if (!res.ok) throw new Error("HTTP " + res.status);
  return res.json();
}

async function demoFetch(){
  const ctrl = new AbortController();
  document.querySelector('#btn-cancel').disabled = false;
  document.querySelector('#btn-cancel').onclick = ()=> ctrl.abort();

  try{
    const usuario = await cargarUsuario(ctrl.signal);
    return {nombre: usuario.name, email: usuario.email};
  }catch(e){
    return {error: e.name+": "+e.message};
  }finally{
    document.querySelector('#btn-cancel').disabled = true;
  }
}

demoFetch().then(console.log);

Consejos 2025: usa AbortController para cancelar, valida res.ok, maneja errores con try/catch, y considera Promise.allSettled para lotes.

Glosario de palabras clave

Event Loop: mecanismo que coordina la ejecución de callbacks cuando las tareas asíncronas finalizan.
Callback: función que se ejecuta cuando una tarea termina.
Promesa: objeto que representa un valor futuro (resuelto o rechazado).
async/await: sintaxis para escribir promesas de forma secuencial.
Concurrencia: ejecutar múltiples tareas en progreso al mismo tiempo.
AbortController: API para cancelar peticiones fetch.
